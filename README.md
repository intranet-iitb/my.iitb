# MyIITB

Landing page shell for IIT Bombay's MyIITB intranet redesign.

Static HTML/CSS. No backend, no roles yet. The tabs (Today, Campus, Employee, Faculty) hold empty applet slots.

## Run locally

Open `index.html` directly, or serve the folder:

```
python -m http.server 8765
```

Styles come from the internal Prototype V3 (`css/main.css`, `components.css`, `dashboard.css`).
